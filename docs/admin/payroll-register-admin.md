Payroll Register Administration

What it does
- Provides administrators with a payroll register report filtered by company and pay date range.
- Displays payroll run totals and employee-level payroll summaries.

Who can use it
- Payroll administrators and finance team members who manage payroll reporting.

Step-by-step
1. Open the Payroll Register page in the administration area.
2. Select a company from the dropdown or choose All companies.
3. Enter a pay date start and end date.
4. Click Refresh to load payroll runs.
5. Review totals and employee-level rows.
6. Click Export CSV to download the CSV file for your own records.

Required permissions
- Access to payroll reports and company payroll data.

Common errors
- The page reports zero runs: ensure the pay date range includes payroll run pay dates.
- The company dropdown does not list a company: verify the company is active.

Troubleshooting
- Confirm payroll runs are saved with a pay date and company assignment.
- Re-open the page if the filter did not update.
- Check for missing employee summary rows if a payroll run has no payroll run employees.

Security cautions
- SSNs and bank account numbers are not included in this report.
- Only payroll totals and employee names are shown.
