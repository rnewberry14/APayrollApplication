# 2026-05-27 W-2 Spreadsheet Import

Added W-2 spreadsheet import workflow.

## Added

- `/import/w2`
- `W2HistoricalRecord` model and database migration
- CSV, tab-delimited, and `.xlsx` parsing through the generic import framework
- Mapping, preview, validation, and confirmation workflow
- Employer EIN masking
- Full employee SSN rejection
- Documentation and tests

## Safety Notes

- No PDF OCR is performed.
- No tax filing is created.
- No external transmission is performed.
- Imported records are marked `historical user-entered data`.
- ClearPath Payroll does not claim the W-2 import validates correctness.
