# 2026-05-26 - Employee Setup

## Summary

Added the local Employee Setup screen for creating and editing employee payroll profile records.

## Changes

- Added `/setup/employees`.
- Added company selector and employee list.
- Added Add New Employee and Edit Employee actions.
- Added tabbed employee setup sections.
- Added direct deposit token setup for up to five accounts.
- Added save/cancel workflow.
- Added documentation and tests.

## Cautions

- It does not submit real ACH or tax filings.
