# Pay Schedule Setup

## What this page does

Pay Schedule Setup creates demo pay schedules with frequency and next pay period dates.

## When to use it

Use it before creating a payroll run.

## Before you begin

Select or create a demo company.

## Step-by-step instructions

1. Open `/setup/pay-schedules`.
2. Select a company.
3. Enter a schedule name.
4. Select weekly, biweekly, semimonthly, or monthly.
5. Enter next pay date.
6. Enter next period start and end dates.
7. Choose active or inactive.
8. Review the preview.
9. Save the schedule.

## What to check

- Preview dates match the fields you entered.
- Validation appears for missing or inconsistent dates.
- Inactive schedules are clearly shown.

## Common messages or errors

- End date before start date: correct the date range.
- Missing company: select a company first.

## What this page does not do

It does not process payroll or determine required pay dates.

## Privacy/safety notes

Confirm pay schedule dates before processing payroll. This is not legal, tax, financial, accounting, payroll compliance, or licensed professional advice.
