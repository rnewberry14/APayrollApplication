# Creating a Payroll Run

## What this page does

The Payroll Run page creates a draft payroll run from a selected company, pay schedule, mode, dates, employees, and entered pay data.

## When to use it

Use it after demo company, employees, and pay schedule records exist.

## Before you begin

Create demo data or set up a company, employees, and pay schedule manually.

## Step-by-step instructions

1. Open `/payroll/create`.
2. Select the company.
3. Select the pay schedule.
4. Choose regular payroll, after-the-fact payroll, or correction payroll placeholder.
5. Confirm pay period start, pay period end, and pay date.
6. Select employees.
7. Enter regular hours, overtime placeholder, manual adjustment, and notes.
8. Click `Create Payroll Run`.
9. Continue to payroll preview or check calculation.

## What to check

- The run is created in Draft status.
- Selected employees appear on the run.
- Hourly employees accept regular hours.
- No taxes are submitted from this page.

## Common messages or errors

- Missing company or schedule: select required values.
- No employees selected: choose at least one employee.
- Invalid hours or adjustment: correct the highlighted value.

## What this page does not do

It does not submit ACH, file taxes, or approve payroll.

## Privacy/safety notes

Use fake/demo pay values only. Do not enter live payroll data.
