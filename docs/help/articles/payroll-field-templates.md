# Payroll Field Templates

## What this page does

Payroll Field Templates provides common optional payroll field templates that can be activated for a demo company.

## When to use it

Use it when testing optional fields such as department, job costing, tips, PTO, bonus, commission, or deduction placeholders.

## Before you begin

Select a demo company.

## Step-by-step instructions

1. Open `/setup/field-templates`.
2. Select a company.
3. Review available templates.
4. Choose a template to activate.
5. Edit the name or code if needed.
6. Save the activated field.
7. Confirm it appears in user-defined fields.

## What to check

- Templates are not activated automatically.
- Activated fields can be edited.
- Wording says templates are optional.

## Common messages or errors

- Duplicate code: choose a different field code.
- Missing company: select a company first.

## What this page does not do

It does not say a field is legally required and does not provide compliance advice.

## Privacy/safety notes

Use optional custom fields for demo data only. Do not enter sensitive identifiers.
