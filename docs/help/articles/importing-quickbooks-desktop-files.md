# Importing QuickBooks Desktop Files

## What this page does

This page imports local CSV or Excel files exported from QuickBooks Desktop reports.

## When to use it

Use it to test report-based imports without connecting directly to QuickBooks Desktop.

## Before you begin

Export a fake/demo report from QuickBooks Desktop or use a demo sample file.

## Step-by-step instructions

1. Open `/import/quickbooks-desktop`.
2. Read the local file instructions.
3. Select the report template.
4. Upload/select the local CSV or Excel file.
5. Map columns.
6. Review validation messages.
7. Preview data.
8. Confirm import only after review.

## What to check

- No QuickBooks credentials are requested.
- No direct SDK/API connection is used.
- Mapping aliases help match common report columns.

## Common messages or errors

- Unknown column: map it manually.
- Unsupported file: export as CSV or Excel.

## What this page does not do

It does not connect to QuickBooks Desktop or store Intuit credentials.

## Privacy/safety notes

Do not import live payroll or sensitive customer files into the demo.
