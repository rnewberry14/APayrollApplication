# Importing QuickBooks Online Files

## What this page does

This page imports local CSV or Excel files exported from QuickBooks Online.

## When to use it

Use it to test QBO exported-file imports without OAuth or direct API access.

## Before you begin

Export a fake/demo QBO file or use a safe demo sample.

## Step-by-step instructions

1. Open `/import/quickbooks-online`.
2. Read the export/import instructions.
3. Select the template.
4. Select a local CSV or Excel file.
5. Map columns.
6. Review validation.
7. Preview data.
8. Confirm import after review.

## What to check

- No Intuit login appears.
- No credentials are requested.
- Data stays in the local demo app.

## Common messages or errors

- Template mismatch: select the template that matches the exported report.
- Missing required field: map or correct the source file.

## What this page does not do

It does not use OAuth, call QBO APIs, or upload files to cloud services.

## Privacy/safety notes

Use fake/demo exported files only.
