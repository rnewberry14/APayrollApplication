# Payroll Register

## What this page does

Payroll Register shows payroll run totals and employee-level summaries for demo payroll data.

## When to use it

Use it after creating, calculating, or approving payroll runs.

## Before you begin

Have at least one demo payroll run.

## Step-by-step instructions

1. Open `/reports/payroll-register`.
2. Select a company.
3. Choose a date range.
4. Review run totals.
5. Review employee-level summaries.
6. Export CSV if needed.
7. Open the CSV and inspect columns.

## What to check

- Filters update the report.
- Totals match the selected date range.
- CSV excludes full SSNs and full bank account numbers.

## Common messages or errors

- No results: adjust date range or create demo payroll.
- Export unavailable: confirm report data is loaded.

## What this page does not do

It does not submit filings, payments, or ACH.

## Privacy/safety notes

Do not export or share files containing live payroll data.
