# Import Mapping

ClearPath Payroll imports local files through a review-and-confirm workflow. Files are parsed locally and are not uploaded to external services.

## What It Does

- Shows import progress from file selection through save.
- Groups mapping fields by employer, employee, pay, tax, direct deposit, check, tax deposit, and optional fields.
- Suggests mappings from common column names.
- Lets users search source columns and target fields.
- Shows mapped field count and unmapped required field count.
- Saves only after user review and confirmation.

## Steps

1. Open an import page.
2. Select a local CSV, tab-delimited, or Excel file.
3. Watch the import progress panel.
4. Review suggested mappings.
5. Use search boxes for large files.
6. Use **Show unmapped only** or **Show required only** to focus the mapping list.
7. Select **Validate**.
8. Review errors, warnings, and preview rows.
9. Confirm the import only after review.

## Safety Notes

Do not import full SSNs, full bank account numbers, routing numbers, passwords, API keys, or live payroll data into the local demo package. ClearPath Payroll does not provide legal, tax, financial, accounting, payroll compliance, or licensed professional advice.
