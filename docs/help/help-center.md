# Help Center

The Help Center is available inside the local demo app at `/help`.

It lists local tester help articles by category, includes a search box, and opens article text from the local documentation files included with the tester package.

## Who can use it

Testers using the local demo package can use the Help Center during manual review.

## How to use it

1. Start the local demo app.
2. Open `/help`.
3. Read the Tester Safety Rules.
4. Search for a feature or browse categories.
5. Click `Open article`.
6. Use the Manual Test Packet and Tester Feedback Form links when testing.
