Tax Liability Report

What it does
- Shows payroll run tax liabilities grouped by tax type for employee withholding and employer taxes.
- Helps payroll administrators review payroll tax obligations by run, with pay date, due date placeholder, and payment status placeholder.
- Supports export to CSV for compliance review and reconciliation.

Who can use it
- Payroll administrators and finance users with access to payroll reporting.

How to use it
1. Open the Tax Liability Report page from the main menu.
2. Select a company or leave the selector set to All companies.
3. Choose a pay date start and end date.
4. Click Refresh to update the report.
5. Review employee withholding and employer tax groups by payroll run.
6. Click Export CSV to download the liability report.

Required permissions
- Read access to payroll run and tax liability data.

Common errors
- No results returned: verify the selected company and pay date range.
- Empty rows: check that payroll runs contain calculated tax lines.

Troubleshooting
- Confirm the payroll run has been calculated and contains tax lines.
- Verify the pay date range covers the payroll run pay date.
- If no data appears, make sure the selected company is active and has recent payroll runs.

Payroll/tax/security cautions
- This report is review-only and does not submit taxes.
- Do not use it to initiate tax payments or ACH transactions.
- It does not display sensitive employee bank account numbers or full SSNs.
