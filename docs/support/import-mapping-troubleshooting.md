# Import Mapping Troubleshooting

ClearPath Payroll support content is limited to software operation. It does not provide legal, tax, financial, accounting, payroll compliance, or licensed professional advice.

## Common Issues

- **Required unmapped fields**: Use **Show required only** and map the missing fields.
- **Too many columns**: Use source and target search boxes, then use **Show unmapped only**.
- **Wrong suggestion**: Change the target field manually before validating.
- **Template buttons do not save**: Template save/load is a placeholder for testing.
- **Validation failed**: Review the row number, field name, and safe error summary.

## Safety Notes

Support should not request full SSNs, full bank account numbers, routing numbers, passwords, API keys, or full import files containing sensitive data.
