# QuickBooks Online Import Troubleshooting

Use this guide when a QuickBooks Online exported file does not map or validate.

ClearPath Payroll provides software tools for payroll calculation, reporting, and data transmission. It does not provide legal, tax, financial, accounting, or payroll compliance advice. Users are responsible for verifying payroll, tax, filing, payment, and compliance requirements with qualified professionals or official agency sources.

## Common Issues

- The wrong QBO template is selected.
- The export does not include expected headers.
- Required target fields are not mapped.
- The workbook data is not on the first worksheet.

## Steps

1. Reopen the report in QuickBooks Online.
2. Export to CSV or Excel again.
3. Confirm the first row contains column headers.
4. Select the matching template.
5. Manually adjust mappings.
6. Validate again.

## Cautions

- This workflow does not verify QBO data.
- This workflow does not connect to the QuickBooks Online API.
- This workflow does not submit payments or filings.
