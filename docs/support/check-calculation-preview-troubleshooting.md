# Check Calculation Preview Troubleshooting

ClearPath Payroll does not provide legal, tax, financial, accounting, or payroll compliance advice. This document covers software behavior only.

## Common Errors

- **Payroll run not found**: Confirm the payroll run ID in the route.
- **No employee checks**: Confirm employees were selected when the draft payroll run was created.
- **Run cannot be recalculated**: The payroll run may already be approved, submitted, or completed.
- **Negative input error**: Enter zero or a positive amount for hours, earnings, deductions, and reimbursements.
- **Negative net pay**: Review earnings, taxes, and deductions before approval.

## Troubleshooting Steps

1. Open the payroll run creation or preview workflow and confirm the run exists.
2. Confirm the run status is Draft or Calculated.
3. Review errors shown at the top of the page.
4. Recalculate one check first.
5. Recalculate all checks after individual inputs look correct.
6. Continue to Payroll Preview / Approval only after errors are resolved.

## Safety Cautions

This page does not approve payroll, submit ACH, submit tax filings, or transmit bank data. Full SSNs and full bank account numbers are not displayed.
